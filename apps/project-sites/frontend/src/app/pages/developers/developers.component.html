Auth model.

API key (v1 — available now)

Pass Authorization: Bearer psk_… in the config header. Every tool call is scope-checked and org-isolated. Mint read-only keys for inspection-only agents; add sites:write to also deploy.

OAuth 2.1 (roadmap)

One-click "Connect ProjectSites" flow via PKCE + RFC 8707 resource indicators. Eliminates the manual paste step entirely. initialize and tools/list are always open — no token needed to discover the catalog.

Test the connection first.

Before wiring your editor, curl the discovery manifest to confirm the server is up:

shell 
curl https://projectsites.dev/api/mcp

Returns the server info, auth how-to, and full tool catalog as JSON.
